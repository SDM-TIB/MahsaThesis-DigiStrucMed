About this model
This is Llama 3.2 1B Instruct with the GuidelineKG with_rules_CoT2 adapter. GAAPO mode supplies the saved best prompt and its original output requirements as the system message. Plain Q&A sends your question directly. Each request is independent. The model does not browse or retrieve documents. Quantized CPU inference can differ from the original research runtime.
Research demonstration. Outputs have not been clinically validated. Questions and answers are kept in this page’s memory and are not saved by the application.
